# Switch Army Knife (SAK)

Outil tout-en-un sous Windows pour gérer, convertir et préparer les fichiers Nintendo Switch (XCI, NSP, NSZ, XCZ).

---

## ⚙️ Prérequis

- Un PC sous **Windows**
- Les clés de votre console : **`prod.keys`** (ou `keys.dat`)

---

## 🚀 Installation

1. Téléchargez et décompressez l'archive de SAK.
2. Placez votre fichier **`prod.keys`** (ou `keys.dat`) dans le dossier **`bin/`** (à côté de `4nxci.exe`).
3. Lancez **`SAK.exe`**.

---

## 🛠️ Fonctions principales

- **Convertir :** XCI vers NSP (et inversement).
- **Compresser / Décompresser :** XCI $\leftrightarrow$ XCZ et NSP $\leftrightarrow$ NSZ.
- **Découper / Fusionner :** Pour installer des jeux $\ge$ 4 Go sur carte SD en FAT32.
- **Mettre à jour :** Fusionner un jeu de base avec ses mises à jour et DLC.
- **Patcher :** Abaisser le prérequis de firmware pour lancer un jeu récent sur un ancien firmware.
- **Outils pratiques :** Création de *forwarder* NRO (raccourcis NSP), extraction de sauvegardes, formatage SD en FAT32.
